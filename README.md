# Windamere's Wonders

An original browser card-drafting civilization game set in the world of Windamere
(sister project of [Colonizers of Windamere](https://github.com/arj873/settlers_of_windamare)).

Players draft cards simultaneously, pass hands, grow a city and raise a wonder.
The ruleset is our own design: see `docs/RULES.md` once it lands.

Stack: TypeScript (strict), PixiJS v8, Vite, Vitest, pnpm. Same stack as the Catan project.

Status: pre-alpha. Built by a team of coding agents; board at
https://github.com/users/arj873/projects/3
